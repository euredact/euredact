# v0.5.0 corpus results

Measured 2026-09-24 on the 152,300-document generated corpus (667,268 scored
labels, `DOB` excluded and reported separately). Both SDKs, both country modes.

> **This release strengthens the evaluation harness.** Recall is now measured
> against whole-identifier masking, so these figures are stricter than those in
> `v0.3.6-corpus-results.md` and the 0.4.0 notes and are not directly
> comparable. See [Evaluation harness](#evaluation-harness).

## Evaluation harness

Recall now requires **every character** of an identifier's span to be masked,
with coverage computed over the union of detections so a name masked as two
adjacent spans still counts once. The previous rule accepted an identifier as
recalled once its literal text no longer appeared in the output — something a
partial redaction also achieves — so a truncated span could score as a complete
detection (`rules-engine#8`).

The IPv6 work in this release is what surfaced the difference, and it is the
reason the harness was tightened: whole-identifier masking is the product
claim, so it is what the metric should measure. Three further outcomes are now
reported alongside recall — **partially masked**, masked under another type,
and not present in the document — so a truncation is visible in the numbers
rather than absorbed into them.

The same rule and category map now run in both SDKs, which agree on every
per-type row below (`rules-engine#12`).

Measured on equal terms:

| | recall (hinted) | recall (blind) |
|---|---:|---:|
| 0.4.0 engine, previous harness | 99.7% | 99.7% |
| 0.4.0 engine, current harness | 99.4% | 99.2% |
| **0.5.0 engine, current harness** | **99.56%** | **99.39%** |

Against the same baseline under the current harness, this release adds
**+0.16pp** hinted and **+0.19pp** blind.

## Known gaps

These are misses, not partial masking, and they predate this release.

- **`NATIONAL_ID_CARD` — 31.73%, 370 missed.** The largest single recall gap in
  the corpus. Unfiled.
- **`PASSPORT` — 81.90%, 194 missed.** Unfiled.
- **`SECRET` — 90.74%, 537 missed and 154 partial.** The 154 are a gold-boundary
  artefact rather than a leak: the gold span includes the `ssh-rsa ` prefix
  while the engine masks the key body, and an algorithm name is not secret
  material. Whether those spans should be redrawn is a corpus question.
- **`POSTAL_CODE` — 98.00%, 1,076 missed.**
- **`CHAMBER_OF_COMMERCE` — 162 partial**, a trailing court letter
  (`HRB 277217 K`) left outside the span.
- **`DOB` — 62.8%** by design: bare dates without keyword or structural context
  are deferred to the cloud tier.

## Reproducing

```bash
make eval                                   # Python, writes evaluation_report.html
cd euredact-ts && npm run test:eval:full     # TypeScript
```

Both need the generated corpus; set `EUREDACT_CORPUS` if it is not at
`../Data-Generation`. On macOS the corpus lives in iCloud Drive and files can be
evicted between runs — a read then returns zero bytes while `stat` still reports
the full size, and the TypeScript harness fails with `Unexpected end of JSON
input`. `dd if=<file> of=/dev/null` materialises them again.
